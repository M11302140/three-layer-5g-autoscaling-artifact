The q9 and q11 trees were recovered from the intermediate build-stage images that the legacy Docker builder keeps (`COPY cmd`, `COPY internal`, `RUN go build`); the binary built in that stage is byte-identical to the one in the tagged image, which ties the source to the image without a git commit. Each snapshot carries its `Dockerfile`; the images were built with `docker build -t hhro-daemon:<tag> .` from the snapshot root.

Password defaults in the source were replaced by empty strings; set `HOST_SSH_PASSWORD`, `HOST_PASS`, `IPSEC_SEG_PASS` and `VYOS_USER_PASSWORD` in the manifest environment (see `SANITIZATION.md`).

## What the snapshots can and cannot reproduce

The "binary sha256" and "exact" statements above refer to the `/src` trees as they were extracted from the build-stage layers, before redaction. The snapshots in this record are those trees after the redaction described in `../SANITIZATION.md`: default passwords replaced by the empty string, the Go module path changed from the authors' GitHub path to `github.com/anon/hhro-daemon`, testbed addresses replaced by `10.0.0.x` / `10.0.1.x` placeholders, and comments in Chinese removed. Each of these changes alters the compiled binary, so building an image from a snapshot in this record yields a different binary and a different image digest from the ones in the table. What the record guarantees is: (1) the digests in the table are those of the images that produced the runs (recorded in the run ledgers and manifests at the time); (2) each snapshot is line-for-line identical to the source of that image except for the listed substitutions and the removed comments (checked by a line-level diff of every Go file; the only non-comment differences are the substitutions in `SANITIZATION.md`); (3) the control laws, knobs and manifests are unchanged. The digests therefore identify the images, not something a reader can rebuild from this record.

Each snapshot carries a short English `README.md` written for this record. The repository's own `README.md` and `docs/` (design notes, pseudocode and proposals in Chinese) were not copied: they are documentation only and have no effect on the built binary, and the paper and the technical report describe the controller. The line-level equivalence statement above concerns the Go sources, `go.mod`/`go.sum`, the `Dockerfile` and the manifests.

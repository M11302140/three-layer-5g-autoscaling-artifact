# The specification ledger

`v8-echelon-algorithm-spec-2026-10.md` is the laboratory notebook of the study: one file, appended to in dated sections (§4.1 … §4.141) from 2026-10-02 to 2026-11-02. Every protocol, pre-registration, ruling, voiding rule, stop condition, result record and correction was written into it at the time, and the paper's claim that each hardware block was registered before it ran rests on the dates and commit times of these sections. `v8-echelon-reconstruction-2026-10.md` is the design proposal (2026-10-02) that the ledger's §4.x sections implement; the ledger refers to it.

Language. The ledger is written in Chinese (with English identifiers, file names, run ids and numbers). It is kept exactly as written, byte for byte, for three reasons: (1) the registrations it holds are evidence only in their original wording and order; a translation would be a new document without the time anchors; (2) the technical report (arXiv) reproduces the content of the sections the paper relies on, in English, with the section numbers; (3) the section headers carry their own timestamps (for example `§4.139 … 跑前寫死(2026-10-28)` = "fixed before the runs, 2026-10-28"), so the anchor is readable without the prose.

How to find a registration cited by the paper. `INDEX.md` in this directory lists every ledger section the paper cites: section number, date, what was registered in one sentence, the table or number of the paper it supports, and the registration file (with embedded timestamp and SHA-256) when one exists. Open the ledger and search for the string `### 4.139` (or `#### 4.139` for a results subsection). Keywords in the headers: 協定 = protocol, 跑前寫死 = fixed before the runs, 登記 = registered, 結果 = results, 更正 = correction, 判讀 = judgement, 作廢 = voided.

Registration timestamps are the commit times recorded in the ledger (the dates in the section headers and the commit hashes named in the sections); the repository history is available to reviewers on request. The snapshot `prereg-snapshot-2026-10-20` (commit fd62007) contains the registration files of the main experiment as of 2026-10-20.
